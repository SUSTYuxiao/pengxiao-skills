- 记录时间：2026-09-15
- 性质：真实行为试验记录，不是模拟推演。除注明外，各轮结果均来自主会话对独立 agent 输出的实际判定
- 基线与输出均为合成测试产物，不含真实标识与生产数字；本文件未拷贝任何原始会话报告

## 第一轮（对应 T1 基线）：判 FAIL

- 设置：general-purpose agent，仅读当版 SKILL.md，不读 examples / acceptance
- 事实基线：抽样 20 台、近 3 天，各节点按相同公式独立重算，结果与生产一致；下游消费端依赖的默认映射分类未核验
- 实际输出：首句"数据加工环节经独立重算验证无误"；正文含"没有算错、没有丢失"；范围限定（20 台 3 天、下游未核验）到后文才补
- 判定：FAIL。两处违规——证据范围扩大（首句无限定地宣称"验证无误"）；模板膨胀（背景 / 发现 / 范围逐项升成标题）

## 规则修订（主会话）

依据第一轮失败修订 SKILL 底线表述，修订在现行 `skills/reader-first/SKILL.md` 中可核对：

- 范围限定紧跟结论，标题与首句也不例外（底线 5）
- 按相同公式重算一致，只能证明本次比对一致，不能据此认定公式正确、数据无丢失或业务无误（底线 5）
- 用户要一段结论时就给自然段，不把"背景、发现、范围"逐项升成标题（底线 4）

## 第三轮（追加修订后，未见基线）

- 追加修订：SKILL 增加首次撰写读 `references/examples.md` 校准、收尾删重复结论 / 规则复述 / 无助当前判断的免责声明、只交付正文（现行 SKILL"动笔与收尾"节可核对）
- 事实基线（未见过的合成基线）：12 家门店最近 7 天订单，抽样订单按生产规则独立重算，金额与系统一致；部分订单使用默认税率，应纳税额未核验
- 实际输出（原文）："本次核查了12家门店最近7天的订单，对抽样订单按生产规则独立重算，金额均与系统结果一致。部分订单使用了默认税率，可能影响实际应纳税额，但应纳税额本身未核验，默认税率与实际适用税率是否一致、影响多大，目前无法确定。因此现有结果只能说明抽样范围内的金额比对一致，不能据此认定税务处理正确；要对税额影响下结论，还需核验实际应纳税额。"
- 主会话判定：事实范围通过（范围与未核验项紧跟结论）；因果克制通过（默认税率与税额差异未下断言）；单段自然表达通过（未堆标题）。末句核验建议与前文略重复，可进一步精炼，非阻断
- 示例迁移的有效性仅由这一个未见样本支持，不能据此宣称所有场景稳定达标

## 局限（不据此声称技能整体有效）

- 没有无 skill 对照组：无法区分输出改善来自 SKILL 还是模型本身能力
- 没有自然触发测试：各轮触发由提示词直接指定，未验证 description 在真实会话中的自动触发可靠性

- 结论范围：已验证的仅是"这几类场景、这几个样本上，改后 SKILL 的输出在事实范围维度通过、表达维度仍有冗余"，不外推到技能整体有效性
