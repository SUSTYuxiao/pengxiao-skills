# reader-first 全局规则（可安装块）

约束对象：面向未参与调查的读者撰写、组织或审阅最终回复与报告的行为。不覆盖去 AI 味、业务验证、HTML 转换；不牺牲技术准确性——允许直白解释，把术语讲清即可。块内内容自包含，复制到目标项目后可独立执行；详细执行条款（改写纪律、安装纪律）在 skill 的 SKILL.md，不随块安装。

## 可安装块

复制下面围栏内的全部内容（含标记行）进目标 AGENTS.md 或独立规则文件：

````markdown
<!-- reader-first:begin -->

## 面向读者的交付

**不要让读者替作者完成解释工作。** 按用户的问题补齐必要的对象、发现、依据、意义与结论范围，不把它们变成必填栏目。

1. **独立可理解**：读者可能没参与相关调查。对象、背景、范围在文中自足；"对方是专业人士"不等于"对方知道当前上下文"。
2. **按用户问题组织**：结构跟着用户的问题走，不按调查经过展开，不套固定模板；内部交接与调查笔记不直接拼进答复。
3. **证据不替代解释**：数字、日志、术语是材料不是结论，讲清它们如何支撑结论；关键术语给一句到位的解释即可，不必展开成教科书。
4. **详略服务理解与决策**：该展开的因果与风险不省略，不按字数压缩，也不为显得完整而膨胀；简单问题给简单回答，不强制结构、不输出额外检查清单。
5. **表达服从事实**：区分事实、推断和未验证项；范围限定紧跟结论，标题与首句也不例外。材料缺口明确指出，不扩大证据效力，不补造影响、背景或动机。

<!-- reader-first:end -->
````

## 安全安装说明（给安装者，不进目标）

1. 只装块内内容：执行条款、示例、验收都留在 skill 内，不复制进目标。目标须为用户指定的具体路径（项目级或用户级），不默认全局、不自行挑选。
2. 先读目标原文；已有语义等价的条款并入即可，不重排、不改写原文措辞。
3. 重复安装：目标已有完整 `reader-first:begin/end` 标记块且内容无漂移 → no-op，如实报告无变更。
4. 目标已有同主题但表述冲突的规则：列出冲突点交用户裁决，不擅自取舍、不静默替换。
5. 更新时拿不到旧版原始模板：不整块覆盖已定制块，只列候选更新并如实报告。
6. 禁止为执行本规则添加 hooks、脚本、CI 或自动检查；未经授权不写任何文件。
