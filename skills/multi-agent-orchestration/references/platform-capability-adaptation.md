# 降级适配（仅当宿主与范式假设不符时使用）

范式默认假设宿主支持：持久自定义 Agent、每 Agent 模型选择、并行子任务。多数现代 Agent 工具满足，直接按 SKILL.md 应用即可。只有确认某项能力缺失时才查本表。

| 缺失能力 | 降级方式 |
| --- | --- |
| 持久自定义 Agent | 将三角色职责、模型层级、只读约束写入 AGENTS.md 规则块末尾，由主智能体内联扮演派发 |
| 独立模型路由 | 全部沿用宿主默认模型；用短提示、轮次上限、最小工具集控制 lite/runner 成本 |
| 并行子任务 | 按 `lite → runner → reviewer` 串行执行，交接工件在主上下文中传递 |
| 工作空间隔离 | 串行写入并显式划分文件所有权，禁止两个任务改同一文件 |
| 工具/权限策略 | 在角色提示词中写明禁止操作（reviewer 不写、lite 不改），由主智能体审查调用 |

## 判断能力是否缺失

按顺序查，找到答案即停止：

1. 宿主的 Agent/设置页面或已有 Agent 配置文件。
2. 宿主官方文档中关于子智能体、模型选择的章节。
3. 都查不到则视为缺失，按上表降级，并在交付中注明。不要虚构宿主能力。
