# 文档模板（docs）

接入建新 docs 或补写主题文档时使用本模板。骨架已内联进 `DOCS_NOTES.md` 第 4 节，目标项目没有本模板也能照规范落笔；本文件只是接入操作时的落笔辅助。

`{{...}}` 为占位符，按目标项目实际替换；文内相对路径按目标实际布局生成，禁止残留机器绝对路径。

```markdown
# {{主题名}}

> 一句话：这是什么，给谁看。

## 目标
为什么存在，解决什么问题。

## 边界
管什么、不管什么，与相邻系统的分界。

## 模块
组成与职责；一节一项，或链接到各模块文档。

## 契约
对外承诺：接口、数据格式、兼容性、时效。

## 操作
怎么用、怎么跑，给最小可执行示例。

## 限制
已知坑、上限、未决问题；未核验的标"待验证"。

## 深入
- 相关 docs：{{相对路径}}
- 相关 notes：{{相对路径}}（"为什么是这样"的证据）
```

写完后自检：只含当前事实，无历史沿革（历史去 notes）；空章节已整节删除，未留空节。
