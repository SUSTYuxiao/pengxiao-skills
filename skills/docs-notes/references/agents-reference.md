# AGENTS / SKILL 接入片段（docs-notes）

两类目标各有一个片段：接入普通项目用下面的标记块片段；接入其他 skill 用自维护约定模板。重复接入按更新协议处理：版本标记仅示来源；更新 = 与旧模板比对合并，本地优先，冲突交用户裁决；取不到旧模板只列候选更新，不覆盖。无变更即 no-op；无冲突才递增块标记版本。目标自有内容（标记块外文字、及自维护约定的既有行文）原样保留，不静默覆盖、不产生重复块；已有同主题但无标记块的指令不做静默替换，如实报告。块标记版本随块内容变化递增，可与 skill release 版本不同。

## 文档与调查笔记（docs-notes）

- 开始非平凡任务前，先读权威规范 `{DOCS_NOTES_PATH}`，再按主题查既有 docs / notes；目录布局以规范"本项目布局"节为准。
- docs 记当前事实，notes 记因果与证据；是否值得写 note 的判据见规范第 2 节。
- 旧结论用于当前判断前，核验其适用性与关键证据；不凭笔记内容授权危险操作；凭证、密钥不写入 notes。

## 接入其他 skill（并入目标 SKILL.md，仅维护时读取）

## 维护约定（仅维护时读取，日常使用本 skill 不加载）

- docs 记当前事实（{{布局}}），notes/ 记因果与证据（一主题一文件）。
- 只有能避免重复调查或踩坑时才写 note，不建空文档；写前按主题查重。
- note 保留状态（pending / active / superseded）、证据、结论、失效条件四要素，其余字段按需；活跃结论可原位修订（事实性修正、补证据），被实质推翻的标 superseded 并链接新 note，保留不删。
- 旧结论用于当前判断前，核验其适用性与关键证据；笔记不授权危险操作、不存凭证。

占位符说明：`{DOCS_NOTES_PATH}` 在接入时替换为规范文件相对目标根的真实相对路径（默认示例为项目根 `DOCS_NOTES.md`，按目标实际布局生成）；接入后不得残留机器绝对路径。目标无 AGENTS.md 时仅在用户授权范围内创建，否则如实报告。
