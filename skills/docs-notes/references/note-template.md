# 调查笔记模板（note）

一主题一文件，文件名含主题词（如 `note-{{主题}}.md`）。骨架已内联进 `DOCS_NOTES.md` 第 5 节，目标项目没有本模板也能照规范落笔；本文件只是接入操作时的落笔辅助。

落笔前先过判据（规范第 2 节）：下个 agent 不知道这些，会不会重复调查、重复踩坑、或做出同样的错误修改？不会就别写。任务计划、执行日志、会话记录不进 notes。

```markdown
# {{主题}}

状态：active            <!-- 被推翻时改 superseded 并链接新 note；不删除本文件 -->
范围：本结论适用于 {{...}}；不适用于 {{...}}
核验日期：{{YYYY-MM-DD}}
证据：
- {{命令 / 查询 / 链接 / 数据，满足可复现}}
问题：{{当时要搞清楚什么}}
结论：{{现在的事实；未核验的写"待验证：…"，不冒充结论}}
决策：{{据此做了什么决定}}
替代方案：{{考虑过什么，为何放弃}}
代价：{{这个决策牺牲了什么}}
失效条件：{{出现什么情况本结论作废}}
```

写完后：结论成熟则迁入 docs 并在 docs 里链接本 note 留证据；本 note 保留。按需落盘，不要求每次任务都产 note。
