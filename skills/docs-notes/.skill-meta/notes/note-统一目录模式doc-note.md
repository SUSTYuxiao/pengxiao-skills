# note：引入统一目录模式（doc-note/）作为推荐

**版本**: v0.5.0  
**日期**: 2026-10-22

## 问题

目标项目平铺模式下，`DOCS_NOTES.md`、`LESSONS.md`、`docs/`、`spec/`、`notes/` 都散落在项目根目录，当项目根目录本身文件较多时显得散乱。

## 决策

引入**统一目录模式**作为新项目推荐：

```
项目根/
├── AGENTS.md           # 留根（入口发现文件）
├── doc-note/           # 统一知识管理目录
│   ├── DOCS_NOTES.md
│   ├── LESSONS.md
│   ├── docs/
│   ├── spec/
│   └── notes/
├── src/
└── ...
```

**关键原则**：

1. 这是建议而非强制，已有项目可选择不迁移（言之有理即可，如迁移成本高、现有结构运转良好）
2. `AGENTS.md` 必须留根，作为宿主入口发现文件
3. 两种模式规范完全一致，只是物理位置不同
4. 接入时询问用户选择模式
