# 措辞细则：客观化表述

适用场景：撰写或修订报告文本（md 与 HTML 同步适用），以及处理用户对既有文本的反馈。

## 三类问题与处理

### 1. 自造压缩词

领域内无通用定义、靠字面压缩拼出的词。识别方法：非本领域读者无法检索、同行需要追问定义的词。

替换方向：拆开为完整表述（「双层聚合」→「两级聚合」；「同族作业」→「同类作业」；「旁证代码」→「对照代码」）。

### 2. 文学化判断词

带叙事色彩或情绪判断的动词/形容词。识别方法：删掉后信息不损失、换成中性词语义不变的，就是。

替换示例（案例实测）：
- 长驱直入 → 未经校验直接覆盖
- 盖回 / 盖成 → 覆盖回 / 覆盖成
- 行为学佐证 → 行为序列佐证
- 翻回 → 恢复为
- 事故本体 → 事故发生时刻
- 断案式标题（案件概要/涉事对象）→ 概要/问题对象

### 3. 无佐证细节（宁缺勿造）

取证素材存在两种解读且无原始细节裁决时，不落笔。案例：TT 重复投递事实已确证（「内容完全相同、仅 rowkey 不同」），但重复两条的秒级归属存在两种表述且无 rowkey 级证据，最终只写确证部分。

边界：时间含义的常见词（如「第一时间」指时间顺序时）不属于清理对象；学科术语、机制名词不属于比喻（见白名单）。

## 技术词白名单（不是比喻，保留）

## 自检

措辞修订后：对被替换词 grep 清零（注意子串误报，先看具体行）；关键数字与消息原文逐字命中；语义零变化（替换前后信息点一致）。
