# 严谨性自检：交付前自迭代

适用场景：HTML 阅读版初稿完成（首次转换或修订同步）后、交付前。执行模型是单次一步到位：在本次会话内完成全部自检与修正，不预设多轮用户反馈。

## 自检清单

1. 结论前置核对：文首按 generation.md「结论先行，按信息组织」交代结论/依据/范围——事故/变更过程类可用其参考例（根因一句话 + 事件经过 + 关键点，因果链与时间线按适用前置）；其他问题类型按对应结构；源 md 无清晰结论层时，可在 HTML 中补建，但只能选取归纳源 md 既有内容，不新增事实或推断，并在此确认。
2. 零丢失核对：对照源 md 确认独有事实及关系没有缺失或含义改变，背景事实的对象、版本、前提与证据等级随之保留；局部比例就地带范围，源内歧义有据澄清。数字、原文、表格与 DOM 计数只作覆盖辅证，不能证明语义正确；不以出现次数相等为硬门槛。
3. 措辞扫描：按 wording.md 三类问题（自造压缩词、文学化判断词、无佐证细节）过一遍全文；有替换时逐项核对每处替换是否改善读者理解、语义零变化、关键信息逐字保留，不以被替换词词频清零作为通过判据（grep 只用于定位受影响行）。
4. 折叠复查：按 folding.md 判断默认状态是否足以理解主要内容；展开后信息完整，折叠只改变呈现层级。
5. 标签配对：`<details>`/`<summary>` 开闭数量一致。
6. 自包含与可视化复查：唯一 `<style>` 块、零外部 `href`/`src`；默认零 `<script>`。若引入轻量图表脚本，须符合 visualization.md（内联、无库、无网络、预算可控、可读），且页面无其他脚本。占比条 / SVG 的长度、点位、颜色映射与同分母数值成比例；不同分母不得放进同一组可直接横向比较的条形。
7. 语义验收：分别按默认与展开状态通读，不回看源 md 与推理过程——能独立说出结论、依据与适用范围，两种状态不矛盾；摘要引用的前置结论须交代其内容或指向文内明确位置。任何一处做不到，回改结构或措辞后重验本项。
8. 浏览器实测：桌面与窄屏默认阅读、折叠点击、锚点跳转均实际检查；ID 唯一、目标可达，来源地址可见，窄屏页面不整体横向溢出（宽表/文本图可局部滚动）。将折叠全部关闭后打印，确认内容仍完整；特殊字符无转义损伤。图形核对可比组与范围，不能只比数值；有图表脚本时另验 JS 开关双态。截图、DOM/token 计数均不能代替默认语义与实际行为验收。

发现问题即改，改完重跑受影响的检查项，全部通过后交付。

## 边界情况：会话中途源 md 被修订

长会话中源 md 可能在本轮转换完成后被继续修订（补证据、措辞修订、结构重排）。此时对 HTML 做重同步：

- 先通读修订后的 md 全文，diff 出变化类型：内容增补 / 措辞替换 / 结构重排（章节增删、重编号、交叉引用变化）。
- 事实方向唯一：md 改 → HTML 跟随；禁止 HTML 单方面改变事实。组织、去重及语义保真的呈现性改写不等于改事实；需补充事实或消歧说明时先写入 md，再同步 HTML。
- 结构重排时，HTML 章节骨架、标题编号、交叉引用一并更新（如 4.1~4.5→3.1~3.5、八章→六章逐处改）；被删内容同步删除，不得「留着备用」。
- 同步时可顺手修复 HTML 自身工程缺陷（URL 双重转义、标签未配对、失效 class），属工程修正而非内容偏离，需在改动说明中单独列出。
- 同步完成后重跑上方自检清单。
