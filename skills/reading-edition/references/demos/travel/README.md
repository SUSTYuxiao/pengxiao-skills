# 团队出行阅读版示例

同一份团队 outing 方案的三个静态阅读版，用于比较信息组织与视觉方向。C、F、G 三版共享同一事实基线，差别只在呈现方式。本目录是静态样例，不是 `reading-edition` 的规范来源或默认模板。

| 文件 | 版本 | 风格 |
|---|---|---|
| `team-outing-options-c.html` | C / 海岛明信片 | 浅蓝、奶油白与珊瑚色，明信片式封面 |
| `team-outing-options-f.html` | F / 慢游画报 | 鼠尾草绿与桃粉，拱窗与植物剪纸 |
| `team-outing-options-g.html` | G / 复古旅行海报 | 黄油黄、海军蓝与番茄红，丝网印刷感 |

## 使用方式

直接用浏览器打开 `index.html` 即可浏览三个版本。页面只使用相对链接，不依赖网络、字体服务或脚本。

只观察它如何处理信息层级、留白、导航和响应式，不照搬旅行主题、配色、装饰、章节划分或 tabs。生成新阅读版时，先按当前文档的内容结构和读者任务自主设计；无需为了参考而每次打开本样例。

## 边界

- 预算是按人数、房型和行程做的规划测算，不是实时机票、酒店库存或可下单报价。
- 页面是静态展示样例，不包含预订、投票、支付或数据采集功能。
- 本目录位于 `reading-edition` skill 的 `references/` 下，会随 `pskills sync` 一起拷贝到宿主项目；它是静态样例，不被 skill 日常流程自动加载。
