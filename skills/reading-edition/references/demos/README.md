# reading-edition 示例

本目录存放 `reading-edition` 的静态成品样例，供观察信息层级、留白、导航与响应式处理。每个子目录是一组共享同一事实基线的多版阅读稿。

**这些示例是参考，不是必须遵循的样式。** 不要照搬其主题、配色、字体、栏数、封面或章节划分；新阅读版按当前文档的类型、受众与长度自主设计。

同时，示例体现的是阅读版的**质量最低标准**，即结论与依据可读、事实零丢失、折叠后信息完整、导航可用、窄屏不整页溢出、单文件自包含。达不到这些是做错了，而不是风格不同。

| 示例 | 说明 |
|---|---|
| [`travel/`](travel/index.html) | 团队秋季出行方案：C / F / G 三版，偏轻量、图文与海报式信息组织 |
| [`report/`](report/index.html) | 技术数据报告：档案总册 / 研究档案 / 技术台账三版，偏长文、表格与证据回查 |

示例不参与 skill 日常生成流程，也不被自动加载；需要时再打开。它们位于 `reading-edition` skill 内，会随 `pskills sync` 一起拷贝到宿主项目。
