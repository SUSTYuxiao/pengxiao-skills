# 发布细则：语雀 HtmlDoc

适用场景：把单文件自包含 HTML 阅读版发布到语雀知识库。

## 要点

- 语雀文档类型区分：普通 Doc 会剥离 `<style>` 标签，内联样式全部失效；HtmlDoc 保留 `<style>`，样式完整生效。
- 发布参数：`type=HtmlDoc` 且正文以 `format=html` 传入，二者缺一不可——只设 type 不设 format 仍可能被按纯文本处理。
- 单文件自包含结构（内联 CSS/SVG、零外部资源）天然适配 HtmlDoc：无外部依赖意味着发布后离线阅读、转发、快照均不丢样式。
- 长文档发布时挂载语雀目录（toc），章节导航由平台生成；HTML 内不必自造目录。
- 原地更新优先于重复建文：同一阅读版再次修订时，更新原文档而不是新建。

## 自检

发布后打开预览确认：样式生效（若有大段无样式文本说明被剥离成普通 Doc）、折叠块可用、中文与特殊字符（消息原文中的 `&`、`+I[1, ...]` 等）无转义损伤。
