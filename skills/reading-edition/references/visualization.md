# 可视化技术分层：占比条、Tailwind 与轻量图表

适用场景：HTML 阅读版需要把报告中的分布、归因桶、豁免阶梯、趋势或多维对比做成图形，或用户要求使用 Tailwind / 图表能力时读取。

## 默认选择

- 同分母占比、互斥归因桶、豁免阶梯、敏感性阶梯：优先用纯 HTML/CSS 横向占比条；每条保留文本数值，图旁标注分母、样本范围、全量/抽样与是否可横向比较。
- 管道 / 链路 / 结构图：优先用 `<pre>` 文本图；确需图形时手写内联 SVG。
- 图形只是呈现层：源报告表格仍进入保真层；禁止让图成为唯一数据载体。
- 非连续嵌套的归因桶不得伪装成漏斗。只有当源报告明确给出逐级嵌套分母与流失关系时才称“漏斗”；豁免阶梯通常应标为“占比条 / 敏感性阶梯”。

## Tailwind CSS

- 允许使用 Tailwind 的条件：用户明确要求，或源项目已有 Tailwind 设计体系且视觉收益明确。
- 只允许把编译后的 Tailwind CSS 内联进唯一 `<style>` 块；禁止 Tailwind Play CDN、外部 CSS、运行时编译脚本。
- 编译产物必须随 HTML 自包含：不得残留 `@import`、外链字体、图片 URL 或网络请求。
- Tailwind 不改变语义、折叠、打印与可访问性要求；折叠仍用原生 `<details>` / `<summary>`。
- 若无法生成可控的编译产物，回退手写 CSS。

## 轻量图表脚本

- 轻量图表是例外，不是默认方案。只有纯 CSS / 内联 SVG 无法清楚表达（如必要的局部交互、密集多维对比）且用户已认可该方向时才引入。
- 允许的形态：少量可读的内联原生 JavaScript，无第三方库、无外链、无网络请求、无 `eval`、无 `document.write`；数据全部内嵌。
- 禁止把 Mermaid、Chart.js、ECharts、D3 等通用图表库作为“轻量图表”引入；禁止用 CDN。
- 工程预算：图表脚本默认不超过 10KB 源码；超过 10KB 时先回退 CSS/SVG，或向用户说明收益与体积并取得明确确认。图表代码必须可读，不做不可审查的压缩块。
- 脚本只服务图表，不得接管折叠、导航、内容生成或事实数据；图表失效时，页面中的表格 / 文本仍能完整传达数据。
- 交付前必须做双态视觉验收：JS 开启与关闭均无内容丢失、无布局破坏；再验证打印与窄屏。开启 JS 时逐项核对图形长度、点位、颜色映射与源 md 数值。
