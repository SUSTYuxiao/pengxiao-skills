# 措辞判据客观化

状态：active
范围：本结论适用于本 skill 的措辞客观化要求与交付前自检；case-20260826.md 案例档案原样保留，其术语处理仅作历史情境参考。
核验日期：2026-09-15
证据：2026-09-15 评审发现：技术词白名单（「懒过期」「两级聚合」等）源自 2026-08-26 单一案例的替换对照，换领域即失效；以 grep 词频清零作通过判据，会把「改善读者理解」偷换成「消除词面」，诱导机械同义替换。0.3.0 版 references/ 下 generation、wording、rigor 的措辞条款即据此修订。
问题：措辞客观化应沿用固定技术词白名单与 grep 清零判据，还是改用可跨领域迁移的通用判据？
结论：白名单是单案例的快照，不具备跨领域效力；grep 清零判据激励为清零而替换，不保证理解改善。
决策：白名单与替换对照降级为历史案例的情境参考（case-20260826.md 保留不动）；通用判据改为「准确 + 读者能否理解」：有定义的术语保留，必要时首次出现带括号解释；自检改为逐项核对每处替换是否改善理解且语义零变化，词频只用于定位受影响行，不作为通过标准。
替代方案：维持白名单制并按领域持续扩充词条——词条来源是单案例快照，永远滞后于领域切换，维护成本持续而覆盖有限，放弃。
代价：失去「grep 一次即判通过」的机械可检查性，自检从词频比对变为逐项语义核对，更依赖执行者判断、耗时更长。
失效条件：用户要求恢复白名单制与 grep 清零判据。
